# Starter knowledge base

70 demo documents (30 FAQ, 15 troubleshooting, 10 user guides, 7 policies, 8 technical).
They are DEMO data, not real company policy.

Each file starts with a metadata block (title, category, audience, status, version).
- audience: Customer = visible to the chatbot for customers; Agent / Internal = not visible to customers.
- status: Approved = the chatbot may use it.

On first start the application imports every .md file in this folder (this README is skipped).
To add your own documents: copy .md files here and press 'Import KnowledgeBase folder' in Admin > Knowledge base.
